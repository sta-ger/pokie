CORRECTION (2026-08-06, third pass): a reviewer found that the migrated `#roundError` panel in
`../pokie-examples/src/ui/ui.ts` carried an inline `style="display: none"`, while
`renderConnectionError`/`clearConnectionError` (in this repo's own
`cli/client/player/renderPlayer.ts`) only ever toggle the element's `hidden` property. An inline
style always wins over the `[hidden] { display: none }` user-agent stylesheet rule the `hidden`
property relies on, regardless of which way `hidden` is set -- so a failed round's readable error,
collapsed technical details, and retry/reconnect controls stayed invisible even though the prior
round's own test suite asserted `hidden === false` and passed. Fixed by switching `#roundError`'s
markup to the same `hidden` attribute mechanism `renderConnectionError`/`clearConnectionError`
already use, and by extending both failure-path tests
(`tests/ui.test.ts`) to walk the element's own ancestor chain via `getComputedStyle` and assert
actual rendered visibility -- not just the `hidden` property -- for the error panel, its message,
its collapsed `<details>`, and the retry/reconnect buttons. Verified the new assertions actually
catch the regression: reverting the markup fix locally reproduces exactly the two test failures
this fix now prevents.
