Usage: create [options] [name] [excess...]

Design a Blueprint Project -- a standalone GameBlueprint JSON file (reels,
symbols, paytable, reel weighting) that feeds into "pokie build" -- through an
interactive wizard when run in a terminal with no --blank/--random ("pokie
create <name>" pre-fills the name), or write one straight from the filled-in
starter template non-interactively via --blank for a bare-minimum one, or
--random for an always-valid randomly generated one, with its reel weighting
already expressed as valid per-reel generation (--seed to reproduce it, --preset
default|variant to pick the generation strategy). For a prepared, immediately
valid package instead, use "pokie init".

Arguments:
  name               optional preset name -- pre-fills the wizard, or names the
                     --blank/--random output
  excess             rejected if present -- this command takes no further
                     positionals

Options:
  --blank            write a bare-minimum blueprint straight from the starter
                     template, no wizard
  --random           write an always-valid, randomly generated blueprint
                     directly, no wizard
  --seed <integer>   reproduce a specific random blueprint (only meaningful with
                     --random)
  --preset <preset>  which random generation strategy to use (only meaningful
                     with --random) (default: "default")
  --out <file>       output path (default: derived from the written blueprint's
                     own manifest id)
  -h, --help         Display help for this command.
