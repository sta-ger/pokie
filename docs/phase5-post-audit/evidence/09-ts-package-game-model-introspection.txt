CLASSIFICATION: INTENTIONAL SUPPORTED LIMITATION
===================================================
Current behavior (tsPackage introspection limited to package.json's name/version/description) is a
deliberate, documented design boundary — stated in buildProjectGameModel.ts's own doc comment, verified by
a dedicated existing test, and documented to end users in docs/cli.md and the Studio UI's own reason
strings. No TODO/FIXME/"unsupported" throw exists anywhere in this path; the absence is handled gracefully
everywhere (a clean per-section "unavailable" status with a human-readable reason), never a crash or a
silent, undocumented omission.
