The explicit `TransactionalRoundStore` contract owns one connection/transaction and
callback-scoped adapters. `SqliteTransactionalRoundStore` commits session state/full RNG,
revision, command envelope, historical response, operation and reference debit/payout
balance together with SQLite WAL/FULL. `ReferenceRoundLedger` is only a local
**test/reference adapter**; external wallets/RGS and independent port configurations
have no ACID claim. The canonical `SessionRuntime` calculation/capture/authority
contracts remain authoritative. The legacy constructor retains weaker compensation.

Public root ESM/CJS exports include the store and ledger. Optional SQLite loads only on
explicit open, with capability errors on unsupported runtimes and no memory fallback.
Public library initialize/readSession/lookupResult/close and the exclusive
`PokieDevServer.transactionalRoundStore` option supply reopen/HTTP composition. Server
shutdown drains accepted commands, including disconnected requests, and closes owned
storage before game release. Serve/dev retain existing options/defaults. Studio
Play/scenarios, outcome-source/pre-generated rounds and portable/browser/WASM consumers
retain their separate support boundaries.
