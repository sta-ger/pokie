## Prior candidate implementation

`AuditRoundRecording` binds model/compatibility/schema/RNG authority, executable
boundaries, original commands and operation identities, ordered mathematical and
saved-stage deliveries, canonical artifacts/result and transactional disposition.
`AuditRoundReplay` restores detached sessions at each accepted boundary and uses
SessionRuntime/game math without settlement/storage dependencies. ReplayRecorder
captures actual execution, retains historical direct retries and supplies the shared
package replay loop to CLI/Studio. Durable results retain evidence at their owning
publication boundary; external preparation reads history from its owned snapshot
without re-entering its queue. Offline replay never applies recorded settlement.

CLI `--recording`, Studio inspect/start/detail/download and Recent Rounds carry the
complete descriptor. Audit verification uses the server verdict; legacy seed replay
is explicitly best-effort, and unsupported custom codecs show their actual reason.
Public state/wins/events use allowlists; canonical generated/debug/executable data
remain in labelled internal exports. Identity history lives in result storage, with
bounded fallbacks and explicit direct-session/recorder release. Artifact schema 1,
WASM compact state and native outcome/fairness profiles remain separate supported
boundaries.
