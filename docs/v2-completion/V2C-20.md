Generated ordinary Node sessions and portable artifacts execute the same maintained WebAssembly math
kernel, with one production model lowering. The host payout fork is removed. ABI 2 imports raw f64 draws,
selects floor(draw × strip length), constructs circular screens and evaluates components. Host RNG,
continuation, ledger and IO remain outside the module. Direct custom calculator injection retains its
existing pipeline; it is never silently lowered. See [the public contract](../wasm-compatibility-boundary.md).
