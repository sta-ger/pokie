# V2C-20 — Shared generated Node / WASM math

Implementation candidate: pending committed-tree verification below. Base:
`7c800465a5606b321f2e03fc697a57205f5f249d`. Immutable brief:
`353a392b3111ffd113e4491567926bed4a2eb9fc9af63b1923912598c635b959`.

Generated ordinary Node sessions and portable artifacts execute the same maintained WebAssembly math
kernel, with one production model lowering. The host payout fork is removed. ABI 2 imports raw f64 draws,
selects floor(draw × strip length), constructs circular screens and evaluates components. Host RNG,
continuation, ledger and IO remain outside the module. Direct custom calculator injection retains its
existing pipeline; it is never silently lowered. See [the public contract](../wasm-compatibility-boundary.md).

| Criterion | Implementation and verification authority |
| --- | --- |
| 1: shared semantics | `SharedSlotMath`, generated calculator/pipeline adapter and portable runtime consume identical code. `WasmSharedMath.test.ts` compiles fresh public ESM/CJS using the existing public-runtime helper, then spawns a native consumer outside Jest resolution. It loads generated dist and recompiled TS, instantiates actual builder bytes independently, and compares first/later draws, stops, screens, components, payout, credits and continuation against existing built-in calculators. Cases include lines/ways/clusters, authored missing/zero and scatter entries, all-wild handling, fractional/mixed stakes, default/explicit paylines and nondefault cluster minimums. Existing goldens are retained and extended. |
| 2: executable identity | ABI/model/math/serialization/RNG versions are explicit. Exact supported lowering bytes, model hash and embedded descriptor must bind to the sidecar before RNG/session creation. Native negatives traverse root/browser/wasm imports, Worker, resolver and Node file adapter; focused API negatives cover invalid signatures, exports, sections and memory/layout. Existing source extraction, freshness, publication cancellation/rollback and Studio registration tests remain authoritative. |
| 3: scalable stops | One i32 stop per reel replaces packed shifts. Distinguishable-symbol native cases cover 30, 31 and 36 total bits, non-power-of-two lengths and late-reel nonzero stops. Runtime validates result bounds without modulo repair. Resource limits and recovery diagnostics are documented; the existing 64 KiB small-artifact budget test is retained. |
| 4: bounded continuation | Artifact-bound v3 snapshots retain only scalar counters, ledger and RNG continuation. Kernel memory has fixed model-derived min=max pages, no session history, and is wiped on runtime disposal. Native ways/clusters run 10,000/100,000 rounds with JSON/fresh-runtime restore, late payout/state parity and per-round continuation accounting. Existing direct/Worker/tape/trace lifecycle checks remain. |
