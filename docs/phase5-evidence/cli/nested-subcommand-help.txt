=== pokie outcomelibrary generate --help ===
Usage: outcomelibrary generate [options] <packageRoot> [excess...]

Generate a WeightedOutcomeLibrary from a built package's own runtime via exact
reel-stop enumeration.

Arguments:
  packageRoot                   <packageRoot> is a package built by "pokie
                                build" (or any package loadPokieGame() can
                                require) whose game opts into exact enumeration
                                via PokieGame.createExactEnumerationSession --
                                see docs/weighted-outcome-library.md#generation.
                                Drives the same session/win-calculation runtime
                                a live round uses; a stateful/unbounded mechanic
                                (e.g. free games) has no exact strategy and
                                fails closed instead of guessing.
  excess                        rejected if present -- this verb takes no
                                further positionals

Options:
  --mode <betModeId>            bet mode to generate for (default: the game's
                                own default bet mode)
  --stake <number>              stake to generate for (default: the game's own
                                default stake)
  --config-hash <hash>          recorded verbatim into the generated library's
                                own diagnostics
  --library-id <id>             id for the generated library (default: derived
                                from the game manifest/mode)
  --max-outcome-space-size <n>  above this raw outcome count, generation
                                requires --bounded instead of an exact sweep
  --bounded                     sample a bounded coverage of the outcome space
                                instead of an exact sweep (requires
                                --sample-size/--seed)
  --sample-size <n>             number of raw draws to sample (requires
                                --bounded)
  --seed <string>               seed for the bounded sample (requires --bounded)
  --estimate                    print the outcome space size/strategy without
                                enumerating or sampling anything
  --dry-run                     alias for --estimate
  --out <file>                  write the generated library JSON to this path
  --resume <file>               resume from a checkpoint written by an earlier
                                cancelled run
  --progress                    print periodic progress to stderr while
                                generating
  --format <format>             only "json" is supported (default: a
                                human-readable summary) (default: "summary")
  -h, --help                    Display help for this command.
