Usage: replay [options] <packageRoot> [excess...]

Best-effort replay of a single round (by seed + round index) from a POKIE game
package.

Arguments:
  packageRoot        an existing POKIE game package, or a native outcome-library
                     bundle (with --mode)
  excess             rejected if present -- this command takes no further
                     positionals

Options:
  --seed <string>    seed to replay against (required for a native
                     outcome-library bundle)
  --round <number>   round index to replay (required)
  --out <file>       write the replay descriptor JSON to this path
  --format <format>  only "json" is supported (validated, but the output is
                     always JSON)
  --mode <modeName>  outcome-library mode to replay (required when <packageRoot>
                     is a native outcome-library bundle)
  -h, --help         Display help for this command.
