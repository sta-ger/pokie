# Historical P6-04 rendered proof

This directory retains only two representative rendered checkpoints from the
historical P6-04 rerun:

- `04-recommended-owned-before-create.png` and its text projection show the
  recommended Design Game state before creation.
- `17-manual-create-workspace.png` and its text projection show the resulting
  managed Project workspace.

The browser profiles, Studio registries, generated Projects, PID files,
automation source, raw terminal logs, repeated failed attempts and debug
captures were runtime/forensic material rather than unique product proof.
They were removed by an ordinary descendant commit and remain recoverable
from Git history. This historical pair does not substitute for any fresh P6V
exact-candidate verification.
