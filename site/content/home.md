# Game math. Your runtime. Your tools.

[Run the examples gallery](gallery.md) · [Open the interactive playground](playground.md)

**FromStan / POKIE** is ISC-licensed open-source game math, a headless JavaScript/TypeScript runtime, and local tooling for developers and math authors. Studio brings design, testing and artifact review into a local producer workspace.

[Start with a Blueprint](getting-started.md) · [Explore the documentation](docs.md) · [Understand the architecture](architecture.md)

## From a model to evidence

Create an editable model, build a supported artifact, validate its structure, simulate with an explicit seed, then inspect reports and replay. Each result has a distinct meaning; simulation and tooling evidence do not confer certification.

- **Author** with Blueprint, PAR or a code-first TypeScript package.
- **Calculate** with composable sessions and shared math contracts.
- **Inspect** with CLI and local Studio, retaining reproducibility and support diagnostics.

## Candidate access

The target identity is `@fromstan/pokie`; the executable remains `pokie`. This checkout is an **unpublished candidate**, not a claim of registry availability or a released 2.0.0. Use a controller-produced local archive or a built checkout as described in [Getting started](getting-started.md#install-the-candidate).

This static site targets **pokie.fromstan.com**. Preparing its files does not deploy it. Hosting and account access are separate steps.

## Open source, clear boundaries

POKIE supplies math/runtime/tooling building blocks. Accounts, KYC, compliance approval, independent RNG certification and production RGS integration remain developer/operator responsibilities. Read the [server boundaries](server.md) before integrating.
